<interfaces>
From engine/deps/prefix/include/dvdread/dvd_reader.h (libdvdread 7.1.1):
- `dvd_reader_t *DVDOpenFiles(void *priv, const dvd_logger_cb *logcb, const char *path, dvd_reader_filesystem_h *fs);` On success the reader owns fs and closes it in DVDClose; on failure the caller keeps fs.
- dvd_reader_filesystem_h and its file/dir handle structs are declared in engine/deps/prefix/include/dvdread/dvd_filesystem.h (stat, dir_open/read/close, file_open/read/seek/close). Read that header for exact member signatures.
From engine/deps/prefix/include/libbluray/bluray.h (libbluray 1.5.0):
- `int bd_open_files(BLURAY *bd, void *handle, struct bd_dir_s *(*open_dir)(void *handle, const char *rel_path), struct bd_file_s *(*open_file)(void *handle, const char *rel_path));` after `bd_init()`.
- BD_FILE_H / BD_DIR_H are declared in engine/deps/prefix/include/libbluray/filesystem.h.
Shipped flow: dvdinfo main = argv -> DVDOpen -> (body: ifoOpen, title tables, JSON) -> DVDClose; bdinfo main = argv -> bd_set_debug_mask(0) -> bd_open -> (body from bd_get_disc_info to before bd_close) -> bd_close.

Seed archive format (defined here, consumed by both harnesses and make_seeds.py):
- Repeated records: u8 path_len (1..64), path bytes (relative, e.g. "VIDEO_TS/VTS_01_0.IFO", "BDMV/PLAYLIST/00800.mpls"), u32 little-endian data_len, data bytes. Parsing stops at the first truncated or invalid record; later duplicate paths replace earlier ones; at most 64 files.
- A path is accepted only if every byte is in [A-Za-z0-9_./], it has no "..", no leading "/", and it starts with the harness's allowed prefix ("VIDEO_TS/" for DVD; "BDMV/" or "CERTIFICATE/" for Blu-ray).
</interfaces>
