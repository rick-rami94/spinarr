<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream download -> engine/deps | Source tarballs fetched over HTTPS, verified by pinned SHA-256 |
| GitHub release asset -> CI runner | cyclonedx-cli binary executed in CI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | engine/build.sh fetch mode | mitigate | Reuses fetch() unchanged: curl --proto '=https' --tlsv1.2 plus pinned SHA-256 check before extraction |
| T-02-06 | Tampering | cyclonedx-cli download in ci.yml | mitigate | Version-pinned asset verified with sha256sum -c against a committed hash before execution |
| T-02-07 | Repudiation | SBOM/notices drifting from what ships | mitigate | One parser (scripts/pins.js) feeds both; --check step fails CI on drift; deterministic output via SOURCE_DATE_EPOCH |
| T-02-SC | Tampering | new tooling | accept | No npm/pip packages added; cyclonedx-cli is a hash-pinned release binary (RESEARCH Package Legitimacy Audit: approved) |
</threat_model>
