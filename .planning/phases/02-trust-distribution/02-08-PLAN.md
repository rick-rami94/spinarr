CIFuzz standalone run (RESEARCH Pattern 9, undocumented): image gcr.io/oss-fuzz-base/clusterfuzzlite-run-fuzzers:v1 (pin by digest), env CFL_PLATFORM=standalone, FILESTORE=filesystem, FILESTORE_ROOT_DIR, WORKSPACE, MODE (code-change|batch|prune|coverage), FUZZ_SECONDS (split across targets), SANITIZER=address, entrypoint python3 /opt/oss-fuzz/infra/cifuzz/run_fuzzers_entrypoint.py.

scripts/fuzz-run.sh contract (consumed by plan 02-10 workflows; identical whichever path the spike picks):
  sh scripts/fuzz-run.sh --mode code-change|batch|prune|coverage --seconds <per-target> --build-out <dir> --corpus <dir> --crashes <dir> --log <file> [--report <dir>]
  - reads and updates <corpus>/<target>/ for each target in <build-out>
  - writes each crashing input to <crashes>/<target>/<name> and its sanitizer output to <crashes>/<target>/<name>.log
  - all fuzzer/runner stdout and stderr go to <log> only; stdout prints only "fuzz-run: mode=<m> targets=<n> crashes=<k>"
  - exit 0 = no crash; exit 3 = at least one crash; any other non-zero = infrastructure failure
  - coverage mode requires a coverage build-out and writes a text summary to <report>/summary.txt
