<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR code -> fuzz job | PR-controlled code builds and runs in CI |
| fuzz job -> private repo / advisories API | Credentialed writes from a public-repo runner |
| fuzzer output -> public job log | Logs are readable by anyone |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-28 | Information Disclosure | crash inputs, stack traces | mitigate | No upload-artifact / run_fuzzers / SARIF (static test + artifacts count check); fuzz output only in $RUNNER_TEMP/fuzz.log, never printed; fuzz-report.js stdout limited to a GHSA link (unit-tested) |
| T-02-29 | Elevation of Privilege | credentials on PR runs | mitigate | No pull_request_target; fork PRs get no secrets and run --mode fork; credential minted per step and scoped to one repo; environment fuzz |
| T-02-30 | Information Disclosure | git auth header | mitigate | base64 header value masked with ::add-mask:: before use; checkout uses persist-credentials: false |
| T-02-31 | Tampering | template injection | mitigate | No ${{ }} in run: blocks (static test) plus zizmor in the audit job |
| T-02-32 | Denial of Service | advisory spam | mitigate | Signature dedupe against crashes/<target>/<sig>/advisory.json in the private repo |
</threat_model>
