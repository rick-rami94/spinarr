<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tag push -> signing credentials | Only v* tag refs can deploy to environment `release` |
| GitHub OIDC -> Entra / Sigstore | Short-lived identity tokens exchanged for signing |
| PSGallery / action marketplace -> runner | Third-party code executed with credentials in scope |
| build legs -> release job | Artifacts cross jobs before being attested |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-33 | Information Disclosure | signing secrets on PR runs | mitigate | Environment expression yields no environment for non-tag runs; secrets exist only in environment `release` (tag rule v*); no pull_request_target (static test) |
| T-02-34 | Tampering | ArtifactSigning module | mitigate | Install-Module -RequiredVersion 0.1.20 equals MODULE_VERSION (static test); hook imports exactly that version |
| T-02-35 | Repudiation | attested digest differs from shipped file | mitigate | Attestation and cosign run in the release job over the downloaded final signed/stapled files; self-verify step before upload |
| T-02-36 | Tampering | cache poisoning into release artifacts | mitigate | No caches in release.yml (static test); setup-node package-manager-cache false |
| T-02-37 | Elevation of Privilege | over-broad token permissions | mitigate | contents/id-token/attestations write only on the release job; build job only id-token for OIDC (Entra subject pinned to environment:release) |
| T-02-38 | Spoofing | unsigned build presented as trusted | mitigate | D-07: half-configured credentials fail; forceCodeSigning + SPINARR_REQUIRE_SIGNING + verify scripts on signed legs; unsigned drafts are pre-release with an "Unsigned build" note |
| T-02-SC | Tampering | new actions (attest, cosign-installer, azure/login) | mitigate | SHA-pinned with version comments; Dependabot github-actions keeps them current; approved in RESEARCH Package Legitimacy Audit |
</threat_model>
