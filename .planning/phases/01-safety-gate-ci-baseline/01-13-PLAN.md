| consented disc folder -> unsandboxed engine | With the sandbox off, any file a parser opens is untrusted input; the identity must change when any such file changes between consent and probe/rip |
| local/NAS/sync writer -> disc folder | An actor with write access to an already-consented folder (the CR-01 precondition) |
